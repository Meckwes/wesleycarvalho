# Wesley Carvalho — Portfolio

Portfolio senior do Wesley Carvalho, Desenvolvedor Full Stack & IA em Fortaleza/CE.

🔗 **Site:** https://wesleycarvalho.vercel.app (apos deploy)

## Stack

- HTML5 + CSS3 + JavaScript vanilla
- Sem framework, sem build step
- Google Fonts: Inter + Plus Jakarta Sans + JetBrains Mono
- Imagens: reais + IA (Gemini)
